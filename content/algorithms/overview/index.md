## 구조

| 경로 | 내용 | 수 |

| `cpp/Beakjoon/` | 백준 C++ 풀이 (문제 번호.cpp) | 112 |

| `notebooks/` | 프로그래머스 Python 풀이 Jupyter 노트북 | 1 |

## 이 시리즈의 글

- [백준 풀이 목록](../baekjoon/) — 번호순 목록과 코드 링크
- [프로그래머스 C++ 풀이 목록](../programmers-cpp/) — 레벨별 목록, SQL 포함
- [SW Expert Academy 풀이 목록](../swea/) — 난이도별 목록
- [프로그래머스 Python 풀이 노트](../programmers-python/) — 노트북과 스크립트의 풀이 코드 전문

문제별 풀이 과정을 적은 글은 [카카오 블라인드 테스트 Solution](/kakao/) 시리즈에 있다.

## 시기

C++ 풀이는 2020년 전후에 집중적으로 풀었고, Python 스크립트는 2021년, 노트북은 2025년 것이다. 언어가 C++에서 Python으로 옮겨 간 흐름이 그대로 보인다.
