Node.js에 기반을 둔 웹 API 프레임워크로서 Express 또는 Fastify 프레임워크를 래핑하여 동작한다. Express와 Fastify는 모두 Node.js를 쉽게 사용하기 위해 만들어진 프레임워크이다.

NestJS는 기본 설치 시 Express를 사용한다. Fastify는 Express와의 벤치마크 결과 2배 정도 빠른 속도를 자랑한다. 그럼에도 NestJS가 기본적으로 Fastify를 사용하지 않는 이유는 Express가 가장 널리 사용되고 있고 수많은 미들웨어가 NestJS와 호환되기 때문이다.
